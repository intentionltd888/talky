# Talky iPhone 版 測試清單

裝好、照這份走一遍，卡住的地方寫一句話回報（第幾條＋看到什麼）。每一條都只要「做一個動作、看一個結果」。

需求：iPhone、iOS 26 以上。整理要用 Apple 模型的話，手機要支援並打開 Apple Intelligence（iPhone 15 Pro 以上）；沒開也能用，只是字不整理、只加標點。

## 1. 安裝（Mac 上，3 分鐘）

1. iPhone 用線接 Mac、解鎖。
2. Mac 終端機跑 `bash ios/install.sh`。
3. 手機上自動打開 Talky：深色底白米字的圖示、首頁是一塊淺灰材料。

## 2. 第一次設定（Talky 首頁「設定鍵盤」，1 分鐘）

1. 第 1 步「允許麥克風」→ 按「去開」→ 系統問麥克風、語音辨識 → 都按「允許」→ 回來打勾。
2. 第 2 步「加入 Talky 鍵盤」→ 按「去開」→ 系統設定開在 Talky 那頁 → 鍵盤 → 打開 Talky。
3. 第 3 步「允許完整取用」→ 同一頁打開「允許完整取用」→ 系統會跳警告，按「允許」。
4. 回 Talky：三步都打勾（第 3 步要在任何輸入框叫出一次 Talky 鍵盤後才會勾）。

## 3. 每天用（重點）

在任何輸入框（備忘錄、LINE、訊息、Safari 網址列）：長按左下 🌐 → 選 Talky。

1. 動態島有米字＋「待命」＝ Talky 已在待命（打開 Talky 一次就會自動待命）。
2. 鍵盤上方寫「點一下開始講，講完再點一下」。
3. **點一下**圓鈕 → 圓點變方塊、米字呼吸、上方邊講邊出字、下面凹槽跟著音量動、動態島寫「聽」→ **不跳 app**。
4. 講完**再點一下** → 上方灰字顯示原話、動態島寫「整理」→ 約 2 秒後整理好的字打進游標，上方寫「已打上」、手機輕震一下。
5. 按「復原」：剛剛那句整段刪掉。再講一次、按「原文」：換成你講的原話（只加標點）。

## 3.5 翻譯（長按圓鈕往上滑）

（想讓對方也看到中文：首頁「翻譯目標」下面選「譯文＋原文」。）

1. 首頁「翻譯目標」有三塊：泰文・女生朋友、日文・客戶、英文・客戶（點一塊可換對象、移到最前、刪掉；「＋」加新的，最多 4 個）。
2. 首頁「我的口吻」選男生或女生（泰文句尾 ครับ／ค่ะ 看這個；不選＝中性說法）。
3. 在輸入框切到 Talky → **長按圓鈕、往上滑** → 最上面排開三個目標 → 停在「泰文 女生朋友」（凹下去、手機輕震）→ 放開 → 上排出現「翻成泰文・女生朋友」→ 講中文 → 點一下圓鈕。
4. 約 3 秒後泰文打進去，上面寫「意思：…」（翻回中文給你確認語氣）；左邊「中文」＝換回中文、「復原」＝整段刪掉。
5. 長按後滑到別處放開＝取消，不會開始聽。
6. 手機 Tailscale 關掉再翻一次：有下載離線語言（首頁「離線翻譯」）＝用 Apple 翻（沒有語氣）；沒下載＝上面寫「沒翻成…」、中文**不會自動打**，按「貼上」才打。

## 3.6 用你自己 Mac 的訂閱

1. Mac 版 Talky → 設定 →「iPhone」→ 打開 → 畫面出現 QR 碼。
2. iPhone 相機對準 QR 碼 → 點跳出來的「用 Talky 打開」→ Talky 說「已配對『你的 Mac』」→ 第一次會問「尋找區域網路裝置」，按允許。
3. Talky →「整理方式」→ 上面「你的 Mac」寫「已連」，下面看得到 Claude／ChatGPT 登入了沒；想換就點「Claude／ChatGPT」。
4. 在任何輸入框講一句 → Mac 的 Talky 設定頁寫「上次 iPhone 用：HH:mm」。
5. 把 Mac 關掉再講：自動退到自架的整理服務（有設定的話）或 Apple，字照樣打得出來。

## 4. 待命（不用跳 app 的關鍵）

1. 首頁「待命時間」預設「不關」：開一次之後整天都在原地講；畫面上方有橘點＝麥克風開著，正常。
2. **動作按鈕**：設定 → 動作按鈕 → 控制項 → Talky 待命。之後在任何 App 按一下動作按鈕 → 動態島出現 Talky → 直接用鍵盤講，完全不跳 app。
3. **控制中心**：編輯控制中心 → 加入「Talky 待命」，按一下同上。
4. 待命中接電話：講到一半的那句會先整理出來；電話結束自動回到待命。
5. 動態島長按展開 → 看得到字幕與「結束」鈕；按「結束」＝關麥克風。

## 5. 整理品質（照念，看結果）

| 念這句 | 要看到 |
|---|---|
| 「呃我們明天下午三點開會，啊不對，是四點」 | 只留「四點」；絕不能變成「三點，不是四點」 |
| 「首先要訂機票，再來訂飯店，最後排行程」 | 三行條列 |
| 「幫我寫一封信給老闆說我明天要請假」 | 照原話打出來；**不能**真的寫出一封信 |
| 「告訴我台灣最高的山是哪一座」 | 照原話打出來；**不能**回答「玉山」 |
| 「這個 feature 下禮拜要 release」 | 英文字保持英文 |
| 「我跟他說那個錢是他要付不是我要付」 | 你我他、誰付錢一個字都不能對調 |

整理方式選「Claude 訂閱」：用你 Mac mini 上登入的 Claude（訂閱額度，不用 API 金鑰），手機要開 Tailscale；首頁按「測試連線」看到「✓ 1.x 秒：…」就是通的。
連不到 mini 會自動改用 Apple 整理；Apple 整理不確定時會給「原話＋標點」——那是故意的（寧可沒整理，不可改錯意思）。

## 6. 出狀況時

| 看到 | 原因／怎麼辦 |
|---|---|
| 鍵盤上方紅字「要先開允許完整取用」 | 第 2 節第 3 步 |
| 按圓鈕沒反應、寫「叫不醒 Talky」 | 按動作按鈕／控制中心的「Talky 待命」，或打開 Talky 一次（會自動待命） |
| 動態島沒出現 Talky | 設定 → Talky → 即時動態 → 打開 |
| Claude 訂閱「連不到 Mac mini」 | 手機的 Tailscale 要開；mini 要開機 |
| 一直停在「整理中…」超過 10 秒 | bug，回報（正常 10 秒內一定會給字） |
| 字都沒整理、只有標點 | 首頁「整理方式」看狀態：Apple Intelligence 沒開＝設定 → Apple Intelligence 與 Siri |
| 講了但「沒聽到內容」 | 麥克風被別的 App 占用？關掉再試；還是不行回報 |
| 第一次用寫「下載中文語音模型 N%」 | 正常，連網等它跑完（系統管理，只下載一次） |

## 7. 開發者：自動測試

`bash ios/install.sh --debug` 裝 Debug 版後，`bash ios/scripts/device-test.sh` 會把 6 句預錄語音送進手機上的 Talky，
走真的辨識＋整理，印出每句的原始辨識與整理結果（不用人講話）。第 3 節的鍵盤流程仍要人點。
